AI Skill

1、mattpocock/skills：面向工程师的 Agent Skill 集合。该项目把作者日常开发使用的 .agents 目录直接开源，内容覆盖需求澄清、写计划、实施到验证的完整工程流程，脚本可直接放进 Claude Code 或任意支持 Skill 的 AI 助手中运行。它的价值在于示范了「一个成熟工程师会把哪些步骤固化成 Skill」。本期小黑盒榜单第 1 名，近 30 天新增 43,396 星。★271,579 ｜ Shell ｜ 推送 2026-09-24

2、blader/humanizer：降低 AI 文案味的改写规则集。它整理了一批典型的「机器腔」特征——排比过密、形容词堆砌、「值得注意的是」这类衔接词、过于工整的三段式，并给出对应的改写方式，让 AI 生成的内容读起来更像真人写的。本期小黑盒榜单第 2 名，近 30 天新增 12,852 星。★52,752 ｜ Python ｜ 推送 2026-09-28

3、nextlevelbuilder/ui-ux-pro-max-skill：网页与 UI 设计智能库。它把配色方案、字体搭配、间距节奏、栅格布局与常见 UX 反模式整理成结构化知识，让 AI 做前端时有据可依而非随手发挥，主要解决「配色土」与「布局呆」两个通病。另有完整中文教程版：bbylw/ui-ux-pro-max-skill-cn（★1,426）。本期小黑盒榜单第 3 名，近 30 天新增 10,577 星。★131,371 ｜ Python ｜ 推送 2026-09-27

4、Leonxlnx/taste-skill：改善 AI 视觉审美的技能包。它约束 AI 在生成网页、封面、图表等视觉产物时不要反复使用那几个套路（渐变紫、居中大标题、三张卡片并列），鼓励更克制、更有场景感的选择。与上一条互补：一个管设计规范，一个管审美品味。本期小黑盒榜单第 4 名，近 30 天新增 10,307 星。★91,050 ｜ 推送 2026-09-26

5、Panniantong/Agent-Reach：让 AI 助手读取多个互联网平台的信息。它把各平台的内容获取、解析与清洗打包成统一接口，免去逐个平台编写爬虫的麻烦，仓库自述为「Give your AI agent eyes to see the entire internet」。本期小黑盒榜单第 5 名，近 30 天新增 9,843 星。★86,081 ｜ Python ｜ 推送 2026-09-15

6、career-ops-hq/career-ops：开源的 AI 求职助手。它会扫描各招聘网站、评估岗位与个人背景的匹配度并按优先级排序，还能顺着职位描述反推需要补齐哪些技能。仓库另配独立的文档站。本期小黑盒榜单第 6 名，近 30 天新增 7,632 星。★73,028 ｜ 推送 2026-09-29

7、mukul975/Anthropic-Cybersecurity-Skills：网络安全技能集合。内含 817 个结构化安全技能，覆盖渗透测试、日志分析、漏洞判定与应急响应等方向，并按安全框架做了映射，适合作为安全测试、安全审计类项目的知识底座。另有中文翻译版。本期小黑盒榜单第 7 名，近 30 天新增 4,790 星。★33,542 ｜ Python ｜ 推送 2026-08-31

8、mvanhorn/last30days-skill：以 30 天为窗口的热点研究技能。它汇总指定主题近一个月的动态、讨论热点与变化趋势，适合做行业观察与趋势追踪。本期小黑盒榜单第 8 名，近 30 天新增 3,691 星。（同名分支 levineam/lastXdays-skill ★48）

9、Egonex-AI/Understand-Anything：把代码仓库转成可交互知识图谱。它讲清模块之间如何调用、数据如何流动、哪些部分是核心，仓库自我定位是「Graphs that teach > graphs that impress」——图是用来让人看懂的，不是用来炫的。适合接手陌生项目时快速建立全局认识。本期小黑盒榜单第 9 名，近 30 天新增 3,449 星。★84,608 ｜ TypeScript ｜ 推送 2026-09-28

10、AgriciDaniel/claude-seo：给 AI 编程助手加 SEO 能力。内含 26 个子技能与 19 个子代理，覆盖关键词研究、技术 SEO 检查（站点地图、结构化数据、抓取问题）以及面向生成式搜索引擎的 GEO 优化。本期小黑盒榜单第 10 名，近 30 天新增 2,692 星。★17,921 ｜ Python ｜ 推送 2026-09-28

Skill 仓库

11、obra/superpowers：经过实战检验的 Skill 集合。内含 20 多个 Skill，覆盖测试驱动开发、系统化调试与协作模式，并自带 /brainstorm、/write-plan、/execute-plan 三个命令，串起「想清楚 → 写方案 → 执行」的流程。★292,617 ｜ Shell ｜ 推送 2026-09-27

12、anthropics/skills：Anthropic 官方的 Skill 仓库。它示范了 Skill 应当怎么写、有哪些官方推荐用法，其中包含被广泛引用的 skill-creator。★178,888 ｜ Python ｜ 推送 2026-09-29

13、affaan-m/ECC：规模最大的 Skill 合集之一。含 68 个 Agent、292 个 Skill 与 94 个命令，另带一个 AgentShield 安全扫描模块。需要某项能力时可以先去这里检索，比从零编写快得多。★269,202 ｜ JavaScript ｜ 推送 2026-09-28

14、farion1231/cc-switch：Claude Code 的配置切换工具。用 Rust 编写，可在多个 API 供应商与模型配置之间一键切换，适合同时使用多家中转服务或多套模型配置的场景。★138,067

15、addyosmani/agent-skills：从机制上约束 AI 偷懒的 Skill 集。由 Addy Osmani 维护，设计思路是强制验证、强制回读、禁止把「看起来完成了」当成「完成了」。★99,746 ｜ JavaScript ｜ 推送 2026-09-26

16、ComposioHQ/awesome-claude-skills：Skill 与插件的索引清单。收录 1000 多个生产级 Skill，按领域分类，适合在需要某项能力时先来检索，避免重复造轮子。另有中文翻译版。★75,810 ｜ Python ｜ 推送 2026-09-18

开源项目

18、paperclipai/paperclip：把一群 Agent 当成公司来管理。它提供组织架构、预算分配与审批流的定义能力，解决多 Agent 协作时「谁负责、能花多少钱、谁批」这类管理问题，而不是技术问题。★93,497 ｜ TypeScript ｜ 推送 2026-09-29

19、stablyai/orca：多编码 Agent 并行开发环境。每个 Agent 拥有独立的 git worktree 互不干扰，并支持把进度推送到手机端。★80,411

20、rohitg00/ai-engineering-from-scratch：从零讲起的 AI 工程课程。共 523 节课，从数学基础一路讲到多智能体系统，强调自己实现而非调用 API，适合系统补齐底层理解。★60,119

21、alibaba/open-code-review：阿里开源的 AI 代码审查工具。走「确定性工程 + LLM 混合」路线，官方给出的 Token 消耗约为通用 Agent 的九分之一。★42,427 ｜ Go ｜ 推送 2026-09-29

22、vectorize-io/hindsight：会学习的 Agent 记忆系统。它不只存对话，而是把经验提炼成可复用的记忆，本期 GitHub Trending 周榜第一。★41,621 ｜ Python ｜ 推送 2026-09-29

23、dream-num/univer：用结构化 API 操作 Office 文档。它把表格与文档做成可编程对象，让 AI 直接检查、修改文档，而不是生成一个文件交给用户。★21,478 ｜ TypeScript ｜ 推送 2026-09-29

24、t8y2/dbx：25 MB 的单文件数据库客户端。支持 100 多种数据库，其中包括达梦、人大金仓等国产库。★21,422

25、yetone/magpie：统一管理本机多家 AI 模型配置。它提供本地网关，做模型切换与统一调用入口，解决配置散落在多个工具里的问题。

26、Niko1221/Strata：把 125B 参数的 MoE 模型塞进 12 GB 显存。采用三路卸载加自推测解码，在 RTX 5070 上实测约 90 tok/s，对小显存运行大模型有参考价值。

Windows 软件

27、PowerToys：微软官方的 Windows 效率合集。包含窗口分区布局（FancyZones）、快速启动器（PowerToys Run）、屏幕文字提取（Text Extractor）、常亮（Awake）以及鼠标定位、批量重命名等工具，全部免费。

28、DevToys：开发者工具箱，完全离线运行。内含 28 个以上工具：JSON/SQL/XML 格式化与校验、JWT 解码、URL 编解码、UUID 生成、正则测试、图片压缩与哈希计算。

29、ShareX：Windows 上功能最全的截图录屏工具。除截图与录屏外，还支持 GIF 制作、OCR 取字、水印，以及截图后自动上传并复制链接，整条流程可自动化。

30、Everything：基于 NTFS 索引的极速文件搜索工具。毫秒级返回全盘文件名结果，速度远超 Windows 自带搜索。

31、Flow Launcher：开源启动器。带插件商店，可搜索程序、文件与网页，也能做计算和查剪贴板历史，可替代开始菜单。

32、Quicker：国产快捷操作面板。按鼠标中键唤出，把常用操作做成按钮；社区有大量现成动作可下载（截长图、OCR、翻译、批量处理等），可定制程度高。

33、FileConverter：资源管理器右键转换工具。安装后直接出现在右键菜单里，支持图片格式互转、文档转 PDF、视频转码与批量压缩。

34、PDFPatcher（PDF 补丁丁）：国产 PDF 处理工具。支持编辑书签、裁剪旋转页面、解除限制、提取合并与转图片，能处理很多商业软件不允许修改的 PDF。

35、Geek Uninstaller：卸载工具。除了卸载软件，还会清理注册表项、安装目录与缓存等残留，也能强制移除卸载失败的程序。

36、Ventoy：多系统启动盘制作工具。不需要反复格式化 U 盘，把 ISO 文件直接拖进去，开机时选择要启动的镜像即可，一张 U 盘可装多个系统安装盘。

37、WinDirStat / SpaceSniffer：磁盘空间可视化工具。用配色方块图把大文件与大目录一眼标出，快速定位空间被谁占用。

38、AutoHotkey / AutoIt：Windows 键鼠屏幕自动化脚本语言。可自定义快捷键、把重复操作写成脚本、制作小工具窗口，几乎任何「天天点这几下」的活儿都能自动化。

39、1Remote：远程会话统一管理器。把 RDP、VNC、SSH、Telnet、SFTP、FTP 统一到一个界面里，配置可加密同步。

插件与桌面布局

40、Windhawk：像给游戏打 MOD 一样定制 Windows。它采用模组化架构，做到不修改系统文件、随时可逆，官方站点公示有 500 多个社区模组、200 万以上累计下载。常用模组包括任务栏样式器、任务栏时钟定制（可显示秒）、垂直任务栏、恢复经典文件资源管理器与经典右键菜单。

41、Rainmeter：桌面小组件工具，中文常称「雨滴桌面」。免费开源（GPL v2），当前版本 4.5.26。它把「皮肤」铺在桌面上，可显示硬件占用仪表、音频可视化、时钟日历与天气；皮肤用简单的描述语言编写，社区皮肤资源丰富。

42、TranslucentTB：任务栏外观改造工具。支持完全透明、模糊、亚克力与不透明四种效果，并提供动态模式——窗口最大化时不透明、桌面无窗口时全透明、全屏游戏时自动隐藏。

43、Seelen UI：替换 Windows 11 默认 Shell 的工具。状态栏的每一项用 JavaScript 编写，可显示 CPU 每核占用、内存、网络速度与磁盘 I/O；支持为每台显示器独立配置 Dock 与工具栏，并提供替代开始菜单（支持 apps:、files:、web: 范围前缀实时搜索）。

44、Winstep Nexus：macOS 风格 Dock。图标从中间向两侧放大、带弹性动画，支持图标分组，还可添加时钟、天气、音量控制等 Docklet。个人使用免费。

45、巨应壁纸：动态壁纸工具。视频、网页、应用都能当作壁纸，相比同类工具更轻量。

一套常见的搭配流程：先用动态壁纸定风格 → TranslucentTB 让任务栏透明 → Rainmeter 放时钟与系统监控 → Nexus 放底部 Dock。三处配色尽量统一，避免花哨。

一条不推荐的

46、cknb6/BunnyCompanion：Windows 桌面宠物 + 本机 AI Agent。概念上，它能让桌面宠物看到屏幕、听懂语音，并内置 40 多个本地工具，属于把 AI 助手做成桌面常驻形态的尝试。但该仓库仅有 1 星、最后推送为 2026-07-17，属于个人实验项目、没有社区验证，不建议安装。列出它是因为这个思路值得关注。
