**对助理的作用**：你现在是**手动截图发给我**；它的自动化上传能让"截图 → 拿到链接"一步完成，将来我们要连续沟通问题时效率更高。

### Everything

**项目**：Everything
**地址**：https://www.voidtools.com/
**用途**：基于 NTFS 索引的极速文件搜索，**毫秒级**返回全盘文件名结果，远超 Windows 自带搜索。
**对助理的作用**：你找文件时快得多；我远程帮你定位文件时也有对应的思路可循。

### Flow Launcher

**项目**：Flow Launcher
**地址**：https://github.com/Flow-Launcher/Flow-Launcher
**用途**：开源启动器，**有插件商店**，可搜索程序/文件/网页、做计算、查剪贴板历史，替代"开始菜单"。
**对助理的作用**：这类工具的组织方式（插件 + 模糊搜索）和我工具页的设计思路相通，可以互相借鉴。

### Quicker

**项目**：Quicker
**地址**：https://getquicker.net/
**用途**：国产快捷操作面板，**按下鼠标中键唤出**，把常用操作做成按钮；社区有大量现成动作可下载（截长图、OCR、翻译、批量处理）。高度可定制，是国产效率工具里的标杆。
**对助理的作用**：你反复做的固定操作（比如整理学籍表格）可以做成 Quicker 动作，**把"教我做"变成"一次配好以后一键点"**。

### FileConverter

**项目**：FileConverter
**地址**：https://github.com/Tichau/FileConverter
**用途**：在**资源管理器右键**直接转换和压缩文件：图片格式互转、文档转 PDF、视频转码、批量压缩。装完就在右键菜单里。
**对助理的作用**：你现在要把文件发给我处理格式，装了这个自己右键就转完了，**省一次来回**。

### PDFPatcher（PDF 补丁丁）

**项目**：PDFPatcher
**地址**：https://github.com/superfashi/PDFPatcher
**用途**：国产 PDF 处理工具：**编辑书签、裁剪旋转页面、解除限制、提取合并、转图片**，能处理很多商业软件不给你动的 PDF。
**对助理的作用**：和我做 PDF 报告的能力互补 —— 它能做那些"要动原文件结构"的活儿。

### Geek Uninstaller

**项目**：Geek Uninstaller
**地址**：https://geekuninstaller.com/
**用途**：卸载软件**并清理残留**（注册表项、安装目录、缓存），还能强制移除卸载失败的程序。
**对助理的作用**：你笔记本上装软件试完想删干净时用得上，能避免残留越攒越多。

### Ventoy

**项目**：Ventoy
**地址**：https://github.com/ventoy/Ventoy
**用途**：做启动盘不用反复格式化 —— ISO 直接拖进去，**开机时选哪个镜像就启动哪个**，一张 U 盘装多个系统安装盘。
**对助理的作用**：将来你要装系统/救援盘，一条命令级别的操作就够，不用来回重刷 U 盘。

### WinDirStat / SpaceSniffer

**项目**：WinDirStat（https://windirstat.net/） / SpaceSniffer（http://uderzo.it/main_products/space_sniffer/）
**用途**：**可视化看磁盘谁占地方** —— 用配色方块图把大文件大目录一眼标出来。
**对助理的作用**：你笔记本 1TB 用久了会满，这类工具能让你（或者我看你截图）**几秒钟定位到元凶**。

### AutoHotKey / AutoIt

**项目**：AutoHotkey（https://www.autohotkey.com/） / AutoIt（https://www.autoitscript.com/）
**用途**：Windows 上的**键鼠屏幕自动化脚本**语言：自定义快捷键、把重复操作写成脚本、做小工具窗口。几乎任何"我天天点这几下"的活儿都能自动化。
**对助理的作用**：**这是"在你电脑上自动化"的现成路径** —— 不用等我把 Hermes 装到你 Windows 上，你自己用 AHK 就能先把最烦的重复操作干掉。

### 1Remote

**项目**：1Remote
**地址**：https://github.com/1Remote/1Remote
**用途**：**远程会话统一管理**：RDP / VNC / SSH / Telnet / SFTP / FTP 都从一个界面进，配置可加密同步。
**对助理的作用**：你以后有一堆云服务器要连时，它比记一堆 IP 和密码省事（**注意：凭据交给密码管理器，不要写在笔记里**）。

## 五、插件 & 桌面布局

### Windhawk

**项目**：Windhawk
**地址**：https://windhawk.net/ （源码 https://github.com/ramensoftware/windhawk）
**用途**：**模组化的 Windows 定制平台** —— 像给游戏打 MOD 一样改系统：**500+ 社区模组、200 万+ 累计下载**、完全免费开源。做到"不修改系统文件、随时可逆"，这是它和传统美化工具最大的区别。常用模组：任务栏样式器、任务栏时钟定制（能显示秒）、**垂直任务栏**、恢复经典文件资源管理器、恢复经典右键菜单、Alt+Tab 只切当前显示器。
**对助理的作用**：**你说 Windows 11 难用的问题，它基本都能治**。而且它是"模组 + 可逆"的设计，风险比改注册表低得多，我可以放心推荐你先拿它试。

### Rainmeter

**项目**：Rainmeter（雨滴桌面）
**地址**：https://www.rainmeter.net/
**用途**：免费开源（GPL v2）的**桌面小组件**工具，当前版本 4.5.26。把"皮肤"铺在桌面上：硬件占用仪表（CPU/内存/磁盘/网络做成圆环）、音频可视化、时钟日历、天气。皮肤用简单的描述语言写，不难学，社区皮肤极多（Mond 极简时钟、Honeycomb 六边形启动器、Enigma 系统监控面板都是经典款）。
**对助理的作用**：你笔记本接显示器办公时，**把系统状态做成桌面仪表**比开任务管理器顺手。它也是**桌面布局类内容的素材源** —— 以后每期报告都有得写。

### TranslucentTB

**项目**：TranslucentTB
**地址**：https://github.com/TranslucentTB/TranslucentTB
**用途**：专门改造**任务栏外观**：完全透明 / 模糊 / 亚克力 / 不透明 / **动态模式**（窗口最大化时不透明、桌面无窗口时全透明、全屏游戏时自动隐藏）。开源免费。
**对助理的作用**：和 Rainmeter 搭配是标配组合（壁纸定调 → 任务栏透明 → 组件点缀）。这类"消除割裂感"的细节，是我们做页面临时最容易忽略的部分。

### Seelen UI

**项目**：Seelen UI
**地址**：https://github.com/eythaann/Seelen-UI
**用途**：**替换 Windows 11 默认 Shell**（不只是一个工具）。可完全脚本化的状态栏（**每一项用 JavaScript 写**，可显示 CPU 每核占用、内存、网络速度、磁盘 I/O、电池）、可独立配置每台显示器的 Dock/工具栏、替代开始菜单（支持 `apps:` `files:` `web:` 范围前缀实时搜索）。
**对助理的作用**：它的**"状态栏项用 JS 写"**这个设计很有意思 —— 等于把桌面变成可编程界面。这种架构思路对我给你做自研工具页有参照价值。

### Winstep Nexus

**项目**：Winstep Nexus
**地址**：https://www.winstep.net/nexus.asp
**用途**：经典的 **macOS 风格 Dock**：图标从中间向两侧放大、有弹性动画、支持图标分组，还能加 Docklet（时钟、天气、音量控制、回收站）。个人使用免费。
**对助理的作用**：和任务栏二者选一即可（都放底部会打架）。推荐给"想换换手感"的场景。

### 巨应壁纸

**项目**：巨应壁纸
**地址**：https://www.juzi.zone/ （官网搜索"巨应壁纸"）
**用途**：把**视频、网页、应用都能当壁纸**的动态壁纸工具，比 Wallpaper Engine 更轻量。
**对助理的作用**：桌面美化的"视觉底子" —— 社区那套标准流程的第一步就是用它定基调（深色壁纸最容易衬托组件和 Dock）。

> **一套现成的组合流程**（社区实测）：① 巨应壁纸定壁纸风格 → ② TranslucentTB 让任务栏透明 → ③ Rainmeter 放极简时钟 + 系统监控 → ④ Nexus 放底部 Dock。**三处配色尽量统一**，避免花里胡哨。
