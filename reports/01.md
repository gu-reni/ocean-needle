### Windows 软件

27、[PowerToys](https://github.com/microsoft/PowerToys)：微软官方的 Windows 效率合集。包含窗口分区布局（FancyZones）、快速启动器（PowerToys Run）、屏幕文字提取（Text Extractor）、常亮（Awake）以及鼠标定位、批量重命名等工具，全部免费。

28、[DevToys](https://github.com/DevToys-app/DevToys)：开发者工具箱，完全离线运行。内含 28 个以上工具：JSON/SQL/XML 格式化与校验、JWT 解码、URL 编解码、UUID 生成、正则测试、图片压缩与哈希计算。

29、[ShareX](https://github.com/ShareX/ShareX)：Windows 上功能最全的截图录屏工具。除截图与录屏外，还支持 GIF 制作、OCR 取字、水印，以及截图后自动上传并复制链接，整条流程可自动化。

30、[Everything](https://www.voidtools.com/)：基于 NTFS 索引的极速文件搜索工具。毫秒级返回全盘文件名结果，速度远超 Windows 自带搜索。

31、[Flow Launcher](https://github.com/Flow-Launcher/Flow-Launcher)：开源启动器。带插件商店，可搜索程序、文件与网页，也能做计算和查剪贴板历史，可替代开始菜单。

32、[Quicker](https://getquicker.net/)：国产快捷操作面板。按鼠标中键唤出，把常用操作做成按钮；社区有大量现成动作可下载（截长图、OCR、翻译、批量处理等），可定制程度高。

33、[FileConverter](https://github.com/Tichau/FileConverter)：资源管理器右键转换工具。安装后直接出现在右键菜单里，支持图片格式互转、文档转 PDF、视频转码与批量压缩。

34、[PDFPatcher（PDF 补丁丁）](https://github.com/superfashi/PDFPatcher)：国产 PDF 处理工具。支持编辑书签、裁剪旋转页面、解除限制、提取合并与转图片，能处理很多商业软件不允许修改的 PDF。

35、[Geek Uninstaller](https://geekuninstaller.com/)：卸载工具。除了卸载软件，还会清理注册表项、安装目录与缓存等残留，也能强制移除卸载失败的程序。

36、[Ventoy](https://github.com/ventoy/Ventoy)：多系统启动盘制作工具。不需要反复格式化 U 盘，把 ISO 文件直接拖进去，开机时选择要启动的镜像即可，一张 U 盘可装多个系统安装盘。

37、[WinDirStat](https://windirstat.net/) / [SpaceSniffer](http://uderzo.it/main_products/space_sniffer/)：磁盘空间可视化工具。用配色方块图把大文件与大目录一眼标出，快速定位空间被谁占用。

38、[AutoHotkey](https://www.autohotkey.com/) / [AutoIt](https://www.autoitscript.com/)：Windows 键鼠屏幕自动化脚本语言。可自定义快捷键、把重复操作写成脚本、制作小工具窗口，几乎任何「天天点这几下」的活儿都能自动化。

39、[1Remote](https://github.com/1Remote/1Remote)：远程会话统一管理器。把 RDP、VNC、SSH、Telnet、SFTP、FTP 统一到一个界面里，配置可加密同步。

### 插件与桌面布局

40、[Windhawk](https://github.com/ramensoftware/windhawk)：像给游戏打 MOD 一样定制 Windows。它采用模组化架构，做到不修改系统文件、随时可逆，官方站点公示有 500 多个社区模组、200 万以上累计下载。常用模组包括任务栏样式器、任务栏时钟定制（可显示秒）、垂直任务栏、恢复经典文件资源管理器与经典右键菜单。

41、[Rainmeter](https://www.rainmeter.net/)：桌面小组件工具，中文常称「雨滴桌面」。免费开源（GPL v2），当前版本 4.5.26。它把「皮肤」铺在桌面上，可显示硬件占用仪表、音频可视化、时钟日历与天气；皮肤用简单的描述语言编写，社区皮肤资源丰富。

42、[TranslucentTB](https://github.com/TranslucentTB/TranslucentTB)：任务栏外观改造工具。支持完全透明、模糊、亚克力与不透明四种效果，并提供动态模式——窗口最大化时不透明、桌面无窗口时全透明、全屏游戏时自动隐藏。

43、[Seelen UI](https://github.com/eythaann/Seelen-UI)：替换 Windows 11 默认 Shell 的工具。状态栏的每一项用 JavaScript 编写，可显示 CPU 每核占用、内存、网络速度与磁盘 I/O；支持为每台显示器独立配置 Dock 与工具栏，并提供替代开始菜单（支持 `apps:`、`files:`、`web:` 范围前缀实时搜索）。

44、[Winstep Nexus](https://www.winstep.net/nexus.asp)：macOS 风格 Dock。图标从中间向两侧放大、带弹性动画，支持图标分组，还可添加时钟、天气、音量控制等 Docklet。个人使用免费。

45、[巨应壁纸](https://www.juzi.zone/)：动态壁纸工具。视频、网页、应用都能当作壁纸，相比同类工具更轻量。

> **一套常见的搭配流程**：先用动态壁纸定风格 → TranslucentTB 让任务栏透明 → Rainmeter 放时钟与系统监控 → Nexus 放底部 Dock。三处配色尽量统一，避免花哨。

### 一条不推荐的

46、[cknb6/BunnyCompanion](https://github.com/cknb6/BunnyCompanion)：Windows 桌面宠物 + 本机 AI Agent。概念上，它能让桌面宠物看到屏幕、听懂语音，并内置 40 多个本地工具，属于把 AI 助手做成桌面常驻形态的尝试。**但该仓库仅有 1 星、最后推送为 2026-07-17**，属于个人实验项目、没有社区验证，不建议安装。列出它是因为这个思路值得关注。
