# Ocean Needle · Issue 01

> Sifting genuinely useful AI Skills out of the open internet.

## Contents

> **In this issue** ｜ Published on the 29th of each month

This issue collects **24 entries**: 14 AI Skills and 10 skill repos & tooling.

> Star counts and last-commit dates were **queried live from the GitHub API on 2026-09-30**.

### AI Skill

1. [mattpocock/skills](https://github.com/mattpocock/skills): A skill collection for engineers. The author open-sourced the `.agents` directory he uses day to day — requirement clarification, planning, implementation and verification, end to end — and the scripts drop straight into Claude Code or any assistant that supports skills. Its real value is as a worked example of which steps a seasoned engineer chooses to freeze into a skill. ★272,254 ｜ Shell ｜ updated 2026-09-29

2. [blader/humanizer](https://github.com/blader/humanizer): A ruleset for taking the AI out of AI writing. It catalogues the usual tells — over-dense parallelism, adjective stacking, connective filler like "it's worth noting", relentlessly tidy three-part structures — and pairs each with a rewrite. The point is prose that reads like a person wrote it. ★52,938 ｜ Python ｜ updated 2026-09-28

3. [nextlevelbuilder/ui-ux-pro-max-skill](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): A design knowledge base for web and UI work. Colour schemes, font pairings, spacing rhythm, grid layout and common UX anti-patterns, all structured so an AI has something to reason from instead of improvising. It targets the two most common failure modes: muddy colour and lifeless layout. A fuller Chinese tutorial port lives at [bbylw/ui-ux-pro-max-skill-cn](https://github.com/bbylw/ui-ux-pro-max-skill-cn) (★1,426). ★131,701 ｜ Python ｜ updated 2026-09-27

4. [Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill): A skill pack for improving an AI's visual taste. It stops generated pages, covers and charts from reaching for the same handful of clichés — purple gradients, a giant centred headline, three cards in a row — and pushes toward more restrained, context-appropriate choices. It complements the entry above: one governs design rules, the other governs taste. ★91,308 ｜ JavaScript ｜ updated 2026-09-26

5. [Panniantong/Agent-Reach](https://github.com/Panniantong/Agent-Reach): Lets an AI assistant read from a range of internet platforms. Content fetching, parsing and cleaning for each platform sit behind one interface, so you don't end up writing a scraper per site. Its own description: "Give your AI agent eyes to see the entire internet". ★86,226 ｜ Python ｜ updated 2026-09-15

6. [career-ops-hq/career-ops](https://github.com/career-ops-hq/career-ops): An open-source AI job-hunting assistant. It scans job boards, scores listings against your background and ranks them, and works backwards from a job description to the skills you'd need to pick up. Ships with a separate [documentation site](https://github.com/career-ops-hq/career-ops-docs) (★70). ★73,096 ｜ JavaScript ｜ updated 2026-09-30

7. [mukul975/Anthropic-Cybersecurity-Skills](https://github.com/mukul975/Anthropic-Cybersecurity-Skills): A cybersecurity skill collection. 817 structured security skills covering penetration testing, log analysis, vulnerability triage and incident response, mapped onto established security frameworks. Useful as the knowledge base underneath a security-testing or auditing project. ★33,591 ｜ Python ｜ updated 2026-08-31

8. [mvanhorn/last30days-skill](https://github.com/mvanhorn/last30days-skill): A trend-research skill on a rolling 30-day window. It summarises recent activity, discussion and shifts around a given topic — handy for industry watching and trend tracking. ★63,215 ｜ Python ｜ updated 2026-09-29

9. [Egonex-AI/Understand-Anything](https://github.com/Egonex-AI/Understand-Anything): Turns a code repository into an interactive knowledge graph: how modules call each other, how data flows, which parts are load-bearing. Its own framing is "Graphs that teach > graphs that impress". Useful for building a global picture fast when you inherit an unfamiliar project. ★84,738 ｜ TypeScript ｜ updated 2026-09-28

10. [AgriciDaniel/claude-seo](https://github.com/AgriciDaniel/claude-seo): Adds SEO capability to a coding assistant. 26 sub-skills and 19 sub-agents covering keyword research, technical SEO checks (sitemaps, structured data, crawl problems) and GEO optimisation aimed at generative search engines. ★17,979 ｜ Python ｜ updated 2026-09-29

11. [handsomestWei/patent-disclosure-skill](https://github.com/handsomestWei/patent-disclosure-skill): A skill pack for Chinese patent practice: mining patentable ideas, drafting disclosures (invention, utility model, design), reading patent text in plain language, watching policy shifts, and helping answer examination opinions. Engineers can use it to turn existing work into compliant disclosure material and cut the back-and-forth with an agency. Chinese-language patent material is scarce, so skills in this space are rare. ★10,553 ｜ Python ｜ updated 2026-09-30

12. [wanshuiyin/Auto-claude-code-research-in-sleep](https://github.com/wanshuiyin/Auto-claude-code-research-in-sleep): A set of skills that let an agent run machine-learning research overnight. Written entirely in Markdown — cross-model review loops, idea discovery, experiment automation — and deliberately framework-free, so it attaches to Claude Code, Codex or any agent. Made for dropping a question before bed and reading the progress in the morning. A risk scan flags it as medium: autonomous loops plus experiment execution can consume resources for a long time and make their own calls. ★16,837 ｜ Python ｜ updated 2026-09-29

13. [kangarooking/cangjie-skill](https://github.com/kangarooking/cangjie-skill): Distils high-density long-form content into an executable skill. Books, long videos and podcasts come out the other end as a SKILL an agent can call directly, rather than a set of notes nobody rereads. Good for turning material you've already consumed — and would never revisit — into reusable capability. Well adapted to Chinese-language sources. ★10,756 ｜ Python ｜ updated 2026-09-26

14. [ayghri/i-have-adhd](https://github.com/ayghri/i-have-adhd): A skill that constrains how a coding agent writes. It forbids burying the conclusion under pages of preamble and demands the answer up front. It doesn't change what the model can do, only the information density of what comes back. Useful in long sessions where "three screens of context first" is slowing you down. ★52,218 ｜ Python ｜ updated 2026-09-19

### Skill repos & tooling

15. [obra/superpowers](https://github.com/obra/superpowers): A battle-tested skill collection. 20-plus skills covering test-driven development, systematic debugging and collaboration patterns, plus three commands — `/brainstorm`, `/write-plan`, `/execute-plan` — that chain think-it-through → write-the-plan → execute. ★293,082 ｜ Shell ｜ updated 2026-09-27

16. [anthropics/skills](https://github.com/anthropics/skills): Anthropic's official skill repository. It demonstrates how a skill should be written and which conventions are recommended, and includes the widely cited `skill-creator`. ★179,044 ｜ Python ｜ updated 2026-09-29

17. [affaan-m/ECC](https://github.com/affaan-m/ECC): One of the largest skill collections around — 68 agents, 292 skills and 94 commands, plus an AgentShield security-scanning module. Worth searching here before writing something from scratch. ★269,736 ｜ JavaScript ｜ updated 2026-09-30

18. [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills): A skill set that mechanically prevents an AI from slacking off. Maintained by Addy Osmani; the design forces verification, forces read-back, and forbids treating "looks finished" as "finished". ★99,980 ｜ JavaScript ｜ updated 2026-09-26

19. [ComposioHQ/awesome-claude-skills](https://github.com/ComposioHQ/awesome-claude-skills): An index of skills and plugins. Over 1,000 production-grade skills sorted by domain — the place to look before building something that already exists. ★75,913 ｜ Python ｜ updated 2026-09-18

20. [cloudflare/security-audit-skill](https://github.com/cloudflare/security-audit-skill): A six-phase security audit framework. One design detail is worth borrowing: an agent that finds a vulnerability is not allowed to declare it real — a fresh agent must be spawned to try to refute it. That's how they cut false positives. ★23,242 ｜ JavaScript ｜ updated 2026-09-14

21. [microsoft/SkillOpt](https://github.com/microsoft/SkillOpt): Treats a skill as something you can train. It iteratively edits a skill description in text space based on an agent's execution traces, with validation gates, and emits a deployable `best_skill.md`. It works on the layer where you don't retrain a model, you fix the prompt asset — useful when you already have an agent but a vague skill description makes execution unstable. ★17,884 ｜ Python ｜ updated 2026-09-05

22. [NVIDIA/SkillSpector](https://github.com/NVIDIA/SkillSpector): A security scanner purpose-built for AI agent skills, detecting vulnerabilities, malicious patterns and risk. When skills come from scattered directories of uneven quality, this is the necessary gate before installing. Apache-2.0, maintained by NVIDIA, rated low risk by directory security scans. ★18,671 ｜ Python ｜ updated 2026-09-30

23. [xingkongliang/skills-manager](https://github.com/xingkongliang/skills-manager): A lightweight desktop app for managing skill libraries across many clients. It syncs and organises agent skills spread across 15-plus coding tools (Cursor, Claude Code, Codex, Copilot and others), solving the problem of skill files scattered everywhere that need manual syncing. Written in Rust. Flagged medium risk by directory security scans, since it writes into multiple agents' configuration directories. ★5,261 ｜ Rust ｜ updated 2026-09-26

24. [farion1231/cc-switch](https://github.com/farion1231/cc-switch): A configuration switcher for Claude Code. Written in Rust, it flips between multiple API providers and model configurations in one click — useful if you use several relay services or keep several model profiles. ★138,817 ｜ Rust ｜ updated 2026-09-30
