Twenty finds, from writing a spec to cutting a video — plus the tooling that keeps agents on a leash.

This issue collects 20 entries: 12 installable AI Skills, 7 skill repos and tools, plus one we would not recommend.

Star counts and last-commit dates were queried live from the GitHub API on 2026-10-29.

AI Skills

  1. huashu-design: One sentence in, a finished design artifact out. It covers web pages, clickable app prototypes, editable PPTX decks, launch animations and infographics, ships a library of 84 styles with sample shots, and offers six directions before narrowing to three. Feed it brand assets — logo, palette, UI screenshots — and the output follows them. Suited to teams with no designer on hand that still have to ship visual material. ★27,965 ｜ HTML ｜ updated 2026-10-23

  2. planning-with-files: Keeps a long task’s plan on disk instead of in the context window. The plan is a Markdown file, re-injected every turn, so work survives /clear and compaction, and a deterministic completion gate stops the agent from calling a half-done job finished. The idea comes from Manus’s file-based planning; installable from npm, the Claude Code plugin marketplace or npx skills, with support for 60+ clients. ★27,738 ｜ Python ｜ updated 2026-10-28

  3. n8n-skills: Gets an agent to produce n8n workflows you can actually import. It covers trigger selection, error handling and expression syntax, and insists on node JSON rather than pseudocode — paste it into n8n and it runs. Handy for drafting repetitive automations once, then adjusting them by hand. ★6,545 ｜ Shell ｜ updated 2026-10-24

  4. SwiftUI-Agent-Skill: SwiftUI conventions from Paul Hudson, the author behind Hacking with Swift. Rather than teaching syntax, it spells out how views compose, how state is managed, and which layout and animation habits are idiomatic — cutting down on code that compiles but does not look like SwiftUI. Built for Claude Code or Codex when writing iOS/macOS interfaces. ★6,390 ｜ — ｜ updated 2026-10-26

  5. asd-ste100-skill: Takes ASD-STE100, the simplified technical English standard from aviation maintenance, and turns it into a skill. It rewrites ambiguous sentences, splits run-ons and normalises terminology, with every rule traceable back to the spec instead of to taste. A good fit for API docs, error messages and operating instructions where wording has to be unambiguous. ★5,761 ｜ Python ｜ updated 2026-10-26

  6. chinese-novelist-skill: Writes full-length Chinese novels, 10 to 50 chapters at a time. A three-layer Q&A pass pins down characters and world-building first; creative memory and cliffhanger hooks then hold continuity across chapters, and a final pass checks for contradictions. Aimed at serialised web fiction, short-story collections and screenplay outlines. ★4,453 ｜ JavaScript ｜ updated 2026-10-28

  7. geo-sleuth: Works out where a photo was taken — and shows its working. It combines OpenStreetMap geometry, terrain skylines, satellite imagery and street view, returning a chain of checkable clues instead of a bare place name. Works with Claude Code, Codex, Cursor, Gemini CLI and other clients. ★4,426 ｜ Python ｜ updated 2026-10-23

  8. ffmpeg-skill: A local video toolbox for coding agents: 42 FFmpeg operations behind a machine-readable contract, plus an MCP server. Cutting, captions, reframing, loudness normalisation and per-platform export profiles are all covered, entirely on-device — no cloud, no API keys. ★3,541 ｜ Python ｜ updated 2026-10-28

  9. stop-that-shit: A hook that blocks agents from overstepping. Mounted on session events, it halts the run when the agent adds unrequested hashes and checksums, quietly widens the scope, or edits unrelated files — blocking rather than warning after the fact. Designed around Codex/GPT workflows, with implementations for several platforms. ★3,301 ｜ JavaScript ｜ updated 2026-10-27

  10. kicad-happy: Agent skills for KiCad electronics work. It reads schematics, reviews PCB layout, runs EMC pre-compliance checks and SPICE simulation, looks up datasheets, sources components and assembles fab-ready output. Useful when revising a board or inheriting someone else’s project — let the agent go over the design first. ★1,529 ｜ Python ｜ updated 2026-10-27

  11. ios-simulator-skill: Lets an agent drive the iOS Simulator itself: install, launch, tap, type, screenshot, read UI state. xcodebuild output is proxied into a compact summary to save tokens. Fits UI automation checks, or letting the agent click through a change after it writes the code. ★1,302 ｜ Python ｜ updated 2026-10-19

  12. gongwen-skills: Chinese official-document writing, covering 22 document types. Output follows the GB/T 9704 layout standard and the register of government offices; missing data is flagged as to-be-supplied rather than invented, length is held to the requested count instead of padded, and the README warns that classified material must never enter a networked model. Aimed at the writing staff of public institutions, hospitals, universities and state-owned enterprises. Licensed under PolyForm Noncommercial — read the terms before commercial use. ★123 ｜ Python ｜ updated 2026-10-22

Skill repos & tooling

  1. vercel-labs/skills: The front door to the skill ecosystem. npx skills find/add/check/update covers search, install, inspection and upgrades, backed by the skills.sh registry, and it recognises and adapts installs for more than 75 coding agents — turning “install a skill” into one scriptable command. A security scan rates it high risk: installs pull and execute skills from third-party sources, telemetry is included, and there is no mandatory confirmation step. ★37,033 ｜ TypeScript ｜ updated 2026-10-29

  2. openai/skills: OpenAI’s official Skills Catalog for Codex. Skills are defined in Markdown and YAML — structure, trigger conditions, installation — with the bulk of the repo being specifications and reference material, and installation kept manual. The obvious place to look when writing your own skill, or when you want to see what a compliant one looks like. ★28,369 ｜ Python ｜ updated 2026-10-28

  3. distilly: Distils how a particular person thinks into a skill package any agent can load — originally released as “Colleague Skill”. It targets the case where someone leaves and their judgement leaves with them: the output is a portable skill directory, not an interview transcript. There is no approval step between the persona analysis and the skill synthesis, and a security scan rates it medium risk, so watch for script execution from the repo. ★26,144 ｜ Python ｜ updated 2026-10-13

  4. google/skills: Google’s official Agent Skills repo, writing the operating conventions of Gemini, Vertex AI, BigQuery and Google Cloud into SKILL.md files. It also ships shell and Python scripts that configure the gcloud CLI and verify the environment, so an agent can follow the documented path instead of guessing parameters from training data. A security scan rates it medium risk: the scripts run system commands and call cloud APIs without an explicit confirmation step. ★21,644 ｜ Python ｜ updated 2026-10-28

  5. iflytek/skillhub: A self-hosted, enterprise-grade skill registry. Skill packages get published and versioned, RBAC and audit logs answer who may install what, and it deploys on Docker or Kubernetes. For organisations that want one place governing skill sources and permissions instead of everyone assembling their own stack. ★5,320 ｜ Java ｜ updated 2026-10-28

  6. cisco-ai-defense/skill-scanner: A security scanner for agent skills from Cisco AI Defense, aimed at prompt injection, data exfiltration and malicious code patterns. Detection is layered: YAML and YARA-X rules, AST and dataflow analysis, an optional LLM judge, and a decision layer that collapses the findings into pass/fail; SARIF output drops straight into CI and pre-commit. Worth running before installing anything third-party — with the caveat its own README states plainly: no findings does not mean no risk. ★2,660 ｜ Python ｜ updated 2026-10-26

  7. alibaba/skill-up: Evaluation and evolution tooling for skills, built to answer whether a skill actually helps. It measures the effect on task completion quality and supports iterating on a version based on those results, treating a skill as a software artifact that deserves regression tests. Written in Go, Apache-2.0. ★1,386 ｜ Go ｜ updated 2026-10-28

Not recommended

  1. Agent-Skills-Hunter: Billed as “the ultimate collection”, bundling 400+ skills in one repository; formerly zhanlincui/ultimate-agent-skills-collection. The problem is the bundling itself: entries carry no per-skill provenance or audit trail, Skillstore graded 49 of its skills individually with the worst at high risk — external commands, filesystem access and scripts — and the last push was 2026-03-10, half a year ago. Installing an unaudited pile just moves the review burden onto whoever installs it; picking individual skills by category is the cheaper route. ★193 ｜ Python ｜ updated 2026-03-10
