# 大海捞针

从各种渠道（GitHub、小黑盒、B站、贴吧、各类信息网站）持续搜集与 **SKILL、AI、大模型、Agent、计算机** 等有关的内容与软件。

- **每 3 天**抓取一次，抓到的内容不与之前重复
- **每周三**分类汇总一期
- 报告以 **md + 服务器渲染的网页** 两种形式发布

## 目录

| 路径 | 说明 |
|---|---|
| `reports/NN.md` | 第 NN 期报告（Markdown 原件） |
| `reports/NN.html` | 第 NN 期报告（渲染后的网页，可直接看） |
| `state/seen.tsv` | 去重台账：已收录条目的唯一键，保证后续不重复推荐 |
| `scripts/report-header.html` | 渲染用的样式表模板 |

## 格式

每条条目包含：**项目 / 地址 / 星 / 用途 / 对助理的作用 / 最近推送**。
星数与推送日期均通过 GitHub API 实时查询，不凭记忆。
