## 简介

大海捞针持续从 **GitHub、小黑盒、B站、贴吧及各类信息网站** 搜集与 **AI Skill、大模型、Agent、开源项目、计算机** 有关的内容与软件。

- **每 3 天**捞取一次，捞到的东西不与之前重复
- **每月 29 号**汇总一期，按类别编排
- 报告同时提供 **Markdown 原件** 与 **可直接阅读的网页版**

## 每期的编排

报告按类别分节，每条包含**项目名、仓库地址与一段说明**：

| 分类 | 收录什么 |
|---|---|
| **AI Skill** | 能给 AI 助手加新能力的技能包与技能库 |
| **开源项目** | 值得关注的新项目、工具与平台 |
| **Windows 软件** | 桌面端实用软件 |
| **插件与桌面布局** | 系统定制、界面美化、效率增强 |

星数与最近推送时间均通过 GitHub API 实时查询，不凭印象填写。
