## 概要

**大海捞针**（中国語で「大海に落ちた針を探す」の意）は、**実用的ですぐ使える AI Skill** を毎月まとめて紹介する月刊ダイジェストです。単体でインストールできるスキルパッケージ、体系化されたスキル集、そしてそれらを支えるツール（管理・最適化・セキュリティスキャン）を扱います。

情報源は GitHub、各種 Skill ディレクトリ、中国語圏の AI コミュニティ、業界フィードなど。1 か月かけて重複を除いた候補から、1 号分を手作業で編成します。

- **毎週水曜**に収集。過去に紹介したものは重複排除用の台帳で除外
- **毎月 29 日**に 1 号を公開
- **1 号あたり最大 20 件** —— 数より質を優先し、水増しはしない
- 各号は **Markdown 原本** と **ブラウザで読める Web 版** の両方を用意

## 各号の構成

記事はカテゴリごとに分かれています。各項目には **プロジェクト名、リポジトリ URL、スター数、何をするものか、最終コミット日** を記載しています。

| カテゴリ | 収録内容 |
|---|---|
| **AI Skill** | すぐインストールして使えるスキルパッケージ |
| **Skill リポジトリとツール** | 体系化されたスキル集、および管理・最適化・セキュリティスキャンのツール |

号によっては **「おすすめしない」** の項目を末尾に置きます。見た目は人気でも未成熟、あるいは更新が止まっているプロジェクトを選び、**なぜ勧めないのか**を明記します。スター数だけで選ぶことはありません。

## 選定基準

次の 3 つをすべて満たすものだけを採用します。

1. **実際に使える** —— インストールすれば実問題を解決する。コンセプトのデモではない
2. **まだ動いている** —— 最近コミットがある。数か月前で止まった半成品ではない
3. **説明できる** —— 「いつ使うか」を 2〜3 文で具体的に書ける。「便利です」では不十分

**スター数と最終コミット日は GitHub API からその都度取得**しています。記憶で埋めることも、検索結果に引用された数字をそのまま使うこともありません。一部の項目には **セキュリティリスクと依存関係** の情報を添えています。
